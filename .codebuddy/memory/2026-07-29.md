### 工具使用注意
- pixts `run <tool> --json-args '{...}'` 在 PowerShell 下因引号转义失败，改用直接子命令 `pixts list-passes --session tiled --limit 500 --sort-by order`。
- PowerShell 重定向 `>` 默认 UTF-16 LE BOM，Python 读取需 `raw[:2]==b"\xff\xfe"` 判断后 `decode("utf-16-le")`。
- list-passes 单次 limit=500 可一次性取完 419 个 pass。
- 复杂查询优先用 Python API（`sys.path.insert(0,r"g:\pix-tool-set\src"); from pix_tool_set import call_tool`），避免 PowerShell 引号/编码问题，且能拿完整结构化数据。
- draw-state / shader-bindings 默认 max_views=12/16 会截断 descriptor table，需显式传 `max_views=80`。
- resource-usage 返回的资源属性在 `data.resource` 子对象（kind/format/width/height/size_bytes/description），不是顶层。

## TileClassificationBuildLists pass 的 shader 资源绑定

Tiled.wpix 中有 3 个 TileClassification 相关 pass，均单 dispatch (24,12,1)=18432 threads，共用 root_signature id=3005（UE5 FrameResources：root[0]=SRV table 64、root[1]=UAV table 16、root[2]=root CBV cb0）。

shader 反射声明的资源（权威，来自字节码）：
- pass 145 DeferredLightingTileClassificationBuildLists (CS 91bb8c98, 5172B, StochasticLighting 下)：cb0=_RootShaderParameters；t0=DeferredLightingTileBitmask(u32,2d)；u0=RWDeferredLightingTileAllocator(struct)；u1=RWDeferredLightingTileData(struct)。
- pass 270 TileClassificationBuildLists (CS dfb985ca, 5612B, LumenReflections 下)：cb0=_RootShaderParameters；t0=LumenTileBitmask(u32,2darray)；u0=RWReflectionClearTileIndirectArgs(u32 buf)；u1=RWReflectionClearTileData(u32 buf)；u2=RWReflectionTileIndirectArgs(u32 buf)；u3=RWReflectionTileData(u32 buf)。
- pass 338 TileClassificationBuildLists (CS f3c03e27, 6260B, LumenScreenProbeGather/Integrate 下)：cb0=_RootShaderParameters；t0=LumenTileBitmask(u32,2darray)；u0=RWIntegrateIndirectArgs(u32 buf)；u1=RWClearUnusedIntegrateTileIndirectArgs(u32 buf)；u2=RWClearUnusedIntegrateTileData(u32 buf)；u3=RWIntegrateTileData(struct)。

运行时绑定（cb0 确定）：pass145→rid2955(4MB buffer)；pass270/338→rid2956(4MB buffer)。

**重要局限**：pix-tool-set 的 root_bindings views 列表不能可靠映射到 shader register。证据：pass 338 的 root[0]/root[1] 全部 80 个 view 都是 rid=896 (2048x2048 A8_UNORM dummy)，明显是占位填充而非真实资源；pass 270 root[0] views[0]=rid102(1x1 dummy) 但 shader t0=LumenTileBitmask。说明 views 是 descriptor heap 物理顺序快照，UE5 FrameResources 子分配导致 register→rid 逐项映射不可靠，需 PIX GUI 或 shader 反汇编确认。
